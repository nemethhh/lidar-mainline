# Kernel modules in the test image. The kernel is built from arm64 defconfig,
# which makes some 800 modules for every supported board; the initramfs only
# carries what this board uses, so U-Boot loads and the kernel unpacks a far
# smaller image. Dependencies (modules.dep, modules.softdep) are added
# automatically; kernel/net, kernel/crypto, kernel/lib and the out-of-tree
# extra/ are kept whole (networking, Wi-Fi security, on-demand helpers).
# One module name per line, '-' and '_' alike.

# dsp service: speaker mix through a loopback
